# Penny tokens (Venn sample)

A tiny design-token source for the [Venn](https://venn-peach-eight.vercel.app) demo. `penny.tokens.json` uses the W3C design-token format.

Fork this repo, change a value (for example `radius.button` from `2` to `12`), push, and Venn will show the contradiction with the matching Figma variable and apply it after you approve.

Sample data only. Not a real product design system.
